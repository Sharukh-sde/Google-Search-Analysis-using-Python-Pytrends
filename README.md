# Google Search Analysis using Python & Pytrends

## About the Project

This project is about analyzing Google search trends in India using Python. I used Pytrends to collect search-interest data for some commonly used technology topics and then analyzed the data using Pandas and Matplotlib.

The main purpose of this project was to understand how the search interest for different topics changes over time.

## Topics Covered

- Python
- SQL
- Power BI
- Data Science
- Machine Learning

## What I Did

- Collected Google Trends data using Pytrends
- Checked and explored the collected data
- Found the highest and lowest search-interest values
- Found the dates with the highest search interest
- Compared different technology keywords
- Calculated average search interest
- Created graphs to understand the trends

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Pytrends
- Jupyter Notebook

## Project Flow

Google Trends → Pytrends → Pandas → Data Analysis → Visualization

## Note

Google Trends shows relative search interest, not the exact number of searches. A value of 100 represents the highest interest point within the selected time period and comparison.
